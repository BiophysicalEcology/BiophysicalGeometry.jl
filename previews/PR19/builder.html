Build an animal ​

Build an animal from simple shapes with sliders and see its areas change. The torso is a dorsal and a ventral half with their own coats, see Back and belly. To it can be joined a head, a neck, a nose or beak, ears, legs, wings and a tail. The body can lie level, be tipped up as in a kangaroo, or stand upright with arms, as in the human tutorial.

The app runs on your own computer, see below.

Run it ​

The app is a small web page served by Julia:

julia
using BiophysicalGeometry, Bonito, WGLMakie
server = BiophysicalGeometry.app()   # opens http://127.0.0.1:8080 in your browser
# ...
close(server)

Legs sized by similarity also need BiologicalScaling.jl installed. The app folder of the repository has the same as a script, and a container to serve it.

The code is the model ​

Every change in the app writes the Julia code for the animal, runs it with BiophysicalGeometry.jl, and shows what the package makes of it: the body, its areas part by part, and its silhouette to the sun. The code is shown under the animal, to copy into Julia and go further: change a join, add a part, or ask for each part's view of the sky, see the tutorials.

The same code can be had without the app, from the settings of the page:

julia
using BiophysicalGeometry
const AB = BiophysicalGeometry.AnimalBuilder
settings = (; mass = 20.0, neck = true, nose = "Nose", ears = "Cone", tail = true)
code = AB.animal_code(settings)
print(code)
using BiophysicalGeometry, Unitful

density = 1000.0u"kg/m^3"
coat = FibrousLayer(8.0u"mm", 30.0u"μm", 3000u"cm^-2")
dorsal = Body(HalfCylinder(; mass = 7.41u"kg", density, axis_ratio_b = 3.0), CompositeInsulation(FibrousLayer(15.0u"mm", 30.0u"μm", 3000u"cm^-2"), FatLayer(0.1, 901.0u"kg/m^3")))
ventral = Body(HalfCylinder(; mass = 7.41u"kg", density, axis_ratio_b = 3.0), CompositeInsulation(FibrousLayer(5.0u"mm", 30.0u"μm", 3000u"cm^-2"), FatLayer(0.1, 901.0u"kg/m^3")))
neck = Body(Cone(; mass = 0.8u"kg", density, axis_ratio_b = 1.0, top_ratio = 0.7), coat)
head = Body(Ellipsoid(; mass = 1.6u"kg", density, axis_ratio_b = 1.5, axis_ratio_c = 1.5), coat)
nose = Body(Cone(; mass = 0.1u"kg", density, axis_ratio_b = 1.0, top_ratio = 0.5), coat)
ear = Body(Cone(; mass = 0.04u"kg", density, axis_ratio_b = 1.5, top_ratio = 0.3), coat)
leg = Body(Cone(; mass = 0.6u"kg", density, axis_ratio_b = 5.0, top_ratio = 0.5), coat)
tail = Body(Cone(; mass = 0.2u"kg", density, axis_ratio_b = 6.0, top_ratio = 0.3), coat)

animal = CompositeBody(;
    parts = (; dorsal, ventral, neck, head, nose, ear_l = ear, ear_r = ear, leg_fl = leg, leg_fr = leg, leg_bl = leg, leg_br = leg, tail),
    joins = (
        Join(dorsal = Attachment(Flat(), FullCover()), ventral = Attachment(Flat(), FullCover())),
        Join(dorsal = Attachment(EndB(0.046148u"m", π / 2), Disc(0.041533u"m")), neck = Attachment(EndA(0.0u"m", 0.0), Disc(0.041533u"m"))),
        Join(neck = Attachment(EndB(0.0u"m", 0.0), Disc(0.028522u"m")), head = Attachment(PoleB(), Disc(0.028522u"m"))),
        Join(head = Attachment(PoleA(), Disc(0.028522u"m")), nose = Attachment(EndA(0.0u"m", 0.0), Disc(0.028522u"m"))),
        Join(head = Attachment(Equator(0.9707963), Disc(0.020923u"m")), ear_l = Attachment(EndA(0.0u"m", 0.0), Disc(0.020923u"m"))),
        Join(head = Attachment(Equator(2.170796), Disc(0.020923u"m")), ear_r = Attachment(EndA(0.0u"m", 0.0), Disc(0.020923u"m"))),
        Join(ventral = Attachment(Lateral(0.47071u"m", 1.920796), Disc(0.031991u"m")), leg_fl = Attachment(EndA(0.0u"m", 0.0), Disc(0.031991u"m"))),
        Join(ventral = Attachment(Lateral(0.47071u"m", 1.220796), Disc(0.031991u"m")), leg_fr = Attachment(EndA(0.0u"m", 0.0), Disc(0.031991u"m"))),
        Join(ventral = Attachment(Lateral(0.083066u"m", 1.920796), Disc(0.031991u"m")), leg_bl = Attachment(EndA(0.0u"m", 0.0), Disc(0.031991u"m"))),
        Join(ventral = Attachment(Lateral(0.083066u"m", 1.220796), Disc(0.031991u"m")), leg_br = Attachment(EndA(0.0u"m", 0.0), Disc(0.031991u"m"))),
        Join(dorsal = Attachment(EndA(0.046148u"m", π / 2), Disc(0.022539u"m")), tail = Attachment(EndA(0.0u"m", 0.0), Disc(0.022539u"m"))),
    ),
)

total_area(animal), skin_area(animal)
julia
animal = AB.build_animal(code)
total_area(animal), skin_area(animal)
(0.8889123794358398 m^2, 0.6977728201369541 m^2)

The animals it starts from ​

julia
using CairoMakie, Main.FigureHelpers
fig = Figure(size = (1100, 480))
for (i, (name, preset)) in enumerate(AB.PRESETS)
    ax = body_axis(fig[fld1(i, 5), mod1(i, 5)]; decorations = false, azimuth = 1.25π, elevation = π / 7,
        title = name, titlesize = 13)
    draw_parts!(ax, AB.build_animal(AB.animal_code(preset)))
end

Controls ​

ControlWhat it sets
mass, posture, pitchthe whole animal; the torso lies level, tips head-up, or stands upright
torso shape, length / width, fatthe two halves of the torso, a HalfCylinder or HalfEllipsoid, with a FatLayer
coat depthsFibrousLayers on the back, the belly, and the head and limbs
head, neck, nose or beak, earseach a fraction of the mass, with its shape and posture
legsnone, two or four; set by hand, or sized from body mass by elastic or geometric similarity, see Geometry and allometry; hind legs can differ
armsfor an upright animal
wings, tailfor a level animal
sunthe direction of the silhouette
