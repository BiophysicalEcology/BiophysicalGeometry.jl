Build an animal ​

Move the sliders to build an animal from simple shapes and see its areas change. The torso is a dorsal and a ventral half with their own coats, see Back and belly. Each animal has its own parts, among a head, a neck, a nose or beak, ears, legs, arms, wings and a tail, and each can be resized and angled.

The numbers are BiophysicalGeometry.jl's own. The page runs the package in your browser, compiled to WebAssembly with Whisk.jl: AnimalBuilder.build makes the animal from the sliders with the package's Unchecked() constructors, and the areas, the triangles drawn and the silhouette to the sun come from the same functions you would call in Julia. No Julia server is involved.

The same animals can be built in Julia:

julia
using BiophysicalGeometry
using BiophysicalGeometry.AnimalBuilder: build, animal, settings

dog = build(animal("Dog"), merge(settings("Dog"), (; mass = 30.0, neckAngle = 20.0)))
total_area(dog), silhouette(dog, Beam(0.0, 0.0, 1.0))

Your own models in a web page ​

Any model can run in a page like this one. Write it as a function from its settings, all numbers, to a CompositeBody, built with Unchecked() constructors so that nothing can throw, and compile it with compile_wasm:

julia
using BiophysicalGeometry, Whisk

compile_wasm("site/model", my_model, (; mass = 20.0, ratio = 3.0))

This writes model.wasm, model.json and biophysical.mjs into site/model. The JavaScript needs no framework, so the model can go in a Vue component, as here, a Bonito app or plain HTML:

js
import { loadBiophysicalModel } from './model/biophysical.mjs'
const spec = await (await fetch('model/model.json')).json()
const model = await loadBiophysicalModel('model/model.wasm', spec)
const { triangles, parts, total, shadow } = model.run(0, { mass: 30 }, [0, 0, 1])

This page compiles its ten animals into one module in the same way, in docs/make.jl.
